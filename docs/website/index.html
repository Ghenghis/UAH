What is the Unity AI Harness?

A self-hosted, local-first kit that stitches together mature open-source tools and adds the missing supervisor layer that every Unity + MCP setup actually needs.

Bring Your Own Agent

Claude Code, Cursor, Codex, OpenCodex — anything that speaks MCP. No vendor lock-in, no SaaS tax.

Built for Real Failure Modes

Domain reloads, Editor hangs, MCP crashes, and Personal-tier license caps are handled, logged, and reported.

Local Assets, Local Builds

Works with the Kenny pack on disk and ships pure-local Unity builds with `harnessctl build --local`.

End-to-End Architecture

A single supervisor orchestrates the Editor, MCP bridges, file-IPC state, heartbeats, and cost metering.

How It Works

From a fresh Windows 11 box to an agent-controllable Unity Editor in a few steps.

1

Clone & Setup

Run bash scripts/setup.sh to create the Unity project, symlink assets, and install the MCP bridge.

2

harnessctl start

Spawns the Editor, primary MCP, writes mcp.json, and starts heartbeats.

3

Agent Takes Control

Your agent discovers the MCP server and starts creating GameObjects, editing scripts, and managing scenes.

4

Build & Ship

harnessctl build --local --target Windows64 produces a runnable player.

Everything Included

A complete operator surface so the Editor stays alive, the agent stays connected, and you stay informed.

Heartbeat Monitor

Detects Editor hangs, MCP death, and restart loops with exponential backoff.

Domain-Reload Survival

Reconnect and health probes keep the agent session alive through C# script edits.

File-IPC State

Quarantine-safe, stale-detecting state store that survives process restarts.

Cost Meter

Parses Claude Code, Codex, and OpenCodex token spend and logs it per turn.

harnessctl doctor

Pre-flight checks for Python, Unity, uv, the Kenny pack, and MCP connectivity.

License Helper

Activates and reports Unity license status with Personal-tier messaging.

Local Unity Build

`harnessctl build --local` drives Unity batchmode directly, no CI tokens required.

GitLab Mirror

One-shot script keeps GitHub and a GitLab remote in sync after every push.

Command Surface

One CLI to supervise the whole pipeline.

harnessctl start Start the Editor, MCP, heartbeats, and cost meter.
harnessctl stop Terminate children and release the harness lock.
harnessctl status Show running state, pids, and MCP health.
harnessctl build Local Unity batchmode build with target aliases.
harnessctl doctor Pre-flight environment checks, JSON or human readable.
harnessctl enable Persist optional MCPs to the harness config.
